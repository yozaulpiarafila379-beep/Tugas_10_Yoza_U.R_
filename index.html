1.Sintaks Factory Constructor

  • Pada program ini, factory constructor digunakan untuk membuat objek melalui method khusus yang mengembalikan instance dari class.
  • Class MyClass memiliki dua cara pembuatan objek, yaitu melalui generative constructor dan factory constructor.
  • Factory constructor create() bertugas membuat dan mengembalikan objek MyClass.
  • Penggunaan factory constructor memberikan fleksibilitas dalam proses pembuatan objek.
  • Pada fungsi main(), program membuat dua objek menggunakan constructor yang berbeda.
  • Program kemudian menampilkan pesan bahwa objek berhasil dibuat.

Kode Dart:


// ==========================================
// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI2A
// ==========================================

class MyClass {

  // Generative constructor
  MyClass();

  // Factory constructor
  factory MyClass.create() {
    return MyClass();
  }
}

void main() {

  var obj1 = MyClass();
  var obj2 = MyClass.create();

  print('Objek 1 berhasil dibuat');
  print('Objek 2 berhasil dibuat');
}

2.Kasus 1 – Singleton Pattern

  • Pada program ini, singleton pattern digunakan untuk memastikan bahwa hanya ada satu objek DatabaseConnection yang dibuat selama program berjalan.
  • Constructor DatabaseConnection._internal() dibuat private sehingga objek tidak dapat dibuat secara langsung dari luar class.
  • Variabel statis _instance digunakan untuk menyimpan satu-satunya instance dari class DatabaseConnection.
  • Factory constructor mengembalikan instance yang sama setiap kali objek diminta.
  • Pada fungsi main(), dua variabel dibuat menggunakan constructor yang sama, tetapi keduanya mengacu pada objek yang sama.
  • Program kemudian menampilkan hasil pengecekan objek dan proses koneksi ke database.

Kode Dart:


// ==========================================
// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI2A
// ==========================================

class DatabaseConnection {

  DatabaseConnection._internal() {
    print('Creating database connection...');
  }

  static final DatabaseConnection _instance =
      DatabaseConnection._internal();

  factory DatabaseConnection() {
    return _instance;
  }

  void connect() {
    print('Connected to database');
  }
}

void main() {

  var db1 = DatabaseConnection();
  var db2 = DatabaseConnection();

  print(identical(db1, db2));

  db1.connect();
  db2.connect();
}

3.Kasus 2 – Object Pool / Caching

  • Pada program ini, factory constructor digunakan untuk menerapkan konsep Object Pool atau Caching.
  • Setiap koneksi yang telah dibuat akan disimpan ke dalam variabel _cache.
  • Jika terdapat permintaan koneksi dengan host dan port yang sama, program akan mengembalikan objek yang sudah ada.
  • Jika koneksi belum tersedia pada cache, program akan membuat objek baru dan menyimpannya ke dalam cache.
  • Teknik ini dapat menghemat penggunaan memori dan meningkatkan efisiensi aplikasi.
  • Pada fungsi main(), program membuat beberapa koneksi dan membandingkan apakah objek yang digunakan sama atau berbeda.

Kode Dart:


// ==========================================
// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI2A
// ==========================================

class ConnectionPool {
  final String host;
  final int port;

  static final Map _cache = {};

  ConnectionPool._(this.host, this.port);

  factory ConnectionPool(String host, int port) {
    var key = '$host:$port';

    if (_cache.containsKey(key)) {
      print('Returning cached connection for $key');
      return _cache[key]!;
    }

    print('Creating new connection for $key');
    var connection = ConnectionPool._(host, port);
    _cache[key] = connection;

    return connection;
  }

  void query(String sql) {
    print('Executing: $sql on $host:$port');
  }
}

void main() {
  var conn1 = ConnectionPool('localhost', 5432);
  conn1.query('SELECT * FROM users');

  print('');

  var conn2 = ConnectionPool('localhost', 5432);
  conn2.query('INSERT INTO products VALUES ("Laptop")');

  print('');

  var conn3 = ConnectionPool('db.example.com', 3306);
  conn3.query('UPDATE orders SET status="Shipped"');

  print('');
  print('conn1 dan conn2 sama? ${identical(conn1, conn2)}');
  print('conn1 dan conn3 sama? ${identical(conn1, conn3)}');
}

4.Kasus 3 – Mengembalikan Subclass

  • Pada program ini, factory constructor digunakan untuk mengembalikan objek dari subclass yang berbeda.
  • Class Shape berperan sebagai class abstrak yang menjadi induk dari beberapa bentuk geometri.
  • Berdasarkan nilai parameter yang diberikan, factory constructor akan membuat objek Circle, Square, Triangle, atau Rectangle.
  • Teknik ini memungkinkan proses pembuatan objek dilakukan secara fleksibel tanpa perlu mengetahui class turunannya secara langsung.
  • Setiap subclass mengimplementasikan method draw() dengan perilaku yang berbeda.
  • Program kemudian menampilkan jenis objek yang sedang digambar sesuai subclass yang digunakan.

Kode Dart:


// ==========================================
// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI2A
// ==========================================

abstract class Shape {
  void draw();

  factory Shape(String type) {
    switch (type) {
      case 'circle':
        return Circle();
      case 'square':
        return Square();
      case 'triangle':
        return Triangle();
      case 'rectangle':
        return Rectangle();
      default:
        return Circle();
    }
  }
}

class Circle implements Shape {
  @override
  void draw() => print('Drawing circle');
}

class Square implements Shape {
  @override
  void draw() => print('Drawing square');
}

class Triangle implements Shape {
  @override
  void draw() => print('Drawing triangle');
}

class Rectangle implements Shape {
  @override
  void draw() => print('Drawing rectangle');
}

void main() {
  var circle = Shape('circle');
  var square = Shape('square');
  var triangle = Shape('triangle');
  var rectangle = Shape('rectangle');

  circle.draw();
  square.draw();
  triangle.draw();
  rectangle.draw();
}

5.Praktik 1 – Factory untuk Configuration

  • Pada program ini, factory constructor digunakan untuk membuat objek konfigurasi berdasarkan environment yang dipilih.
  • Class AppConfig berfungsi untuk menyimpan konfigurasi aplikasi seperti environment, API URL, dan debug mode.
  • Berdasarkan parameter yang diberikan, factory constructor akan mengembalikan konfigurasi Development, Production, atau Staging.
  • Teknik ini memungkinkan pembuatan objek konfigurasi dilakukan secara terpusat tanpa perlu memanggil constructor tertentu secara langsung.
  • Setiap environment memiliki nilai konfigurasi yang berbeda sesuai kebutuhan pengembangan aplikasi.
  • Program kemudian menampilkan informasi konfigurasi yang digunakan berupa environment, API URL, dan debug mode.

Kode Dart:


// ==========================================
// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI2A
// ==========================================

class AppConfig {
  final String environment;
  final String apiUrl;
  final bool debugMode;

  AppConfig._development()
      : environment = 'development',
        apiUrl = 'http://localhost:3000',
        debugMode = true;

  AppConfig._production()
      : environment = 'production',
        apiUrl = 'https://api.example.com',
        debugMode = false;

  AppConfig._staging()
      : environment = 'staging',
        apiUrl = 'https://staging.example.com',
        debugMode = true;

  factory AppConfig.fromEnvironment(String env) {
    switch (env.toLowerCase()) {
      case 'dev':
        return AppConfig._development();
      case 'prod':
        return AppConfig._production();
      case 'stage':
        return AppConfig._staging();
      default:
        return AppConfig._development();
    }
  }

  void printConfig() {
    print('Environment : $environment');
    print('API URL     : $apiUrl');
    print('Debug Mode  : $debugMode');
    print('------------------------');
  }
}

void main() {
  var dev = AppConfig.fromEnvironment('dev');
  var prod = AppConfig.fromEnvironment('prod');
  var stage = AppConfig.fromEnvironment('stage');

  dev.printConfig();
  prod.printConfig();
  stage.printConfig();
}

6.Factory dengan Named Constructors

  • Pada program ini, factory constructor digunakan untuk membuat objek User melalui beberapa cara yang berbeda.
  • Class User berfungsi untuk menyimpan data pengguna berupa ID, nama, dan email.
  • Factory constructor fromJson() digunakan untuk membuat objek User dari data JSON yang diterima.
  • Factory constructor guest() digunakan untuk membuat objek pengguna tamu dengan data default yang telah ditentukan.
  • Factory constructor create() digunakan untuk membuat objek pengguna baru berdasarkan data yang diberikan.
  • Program kemudian menampilkan informasi setiap objek User yang berhasil dibuat menggunakan factory constructor yang berbeda.

Kode Dart:


// ==========================================
// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI2A
// ==========================================

class User {
  final String id;
  final String name;
  final String email;

  User._({
    required this.id,
    required this.name,
    required this.email,
  });

  factory User.fromJson(Map json) {
    return User._(
      id: json['id'],
      name: json['name'],
      email: json['email'],
    );
  }

  factory User.guest() {
    return User._(
      id: '0',
      name: 'Guest',
      email: 'guest@example.com',
    );
  }

  factory User.create(String name, String email) {
    return User._(
      id: '001',
      name: name,
      email: email,
    );
  }

  @override
  String toString() {
    return 'User(id: $id, name: $name, email: $email)';
  }
}

void main() {
  var user = User.fromJson({
    'id': '123',
    'name': 'Alice',
    'email': 'alice@example.com'
  });

  var guest = User.guest();

  var newUser = User.create(
    'Bob',
    'bob@example.com',
  );

  print(user);
  print(guest);
  print(newUser);
}
